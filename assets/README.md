# 📁 Team Fantastic Assets

This directory stores all visual assets for the Fantastic 4 GitHub Organization profile.

### Expected & Supported Asset Files:
| File Name | Purpose | Recommended Dimensions / Format |
|---|---|---|
| `banner.png` (or `banner.jpg`) | Main Organization Hero Banner | ~1280x400 or 1920x600 (PNG / JPG / WebP) |
| `team-visual.png` (or `.jpg`) | Side card visual for featured initiatives | 500x500 or 800x800 (Square or 4:5 ratio) |
| `icons8-one-50.png` | Number 1 bullet icon | 50x50 or 64x64 PNG |
| `icons8-two-64.png` | Number 2 bullet icon | 50x50 or 64x64 PNG |
| `icons8-three-64.png` | Number 3 bullet icon | 50x50 or 64x64 PNG |
| `icons8-four-64.png` | Number 4 bullet icon | 50x50 or 64x64 PNG |
| `icons8-share-24.png` | External link / share icon | 24x24 or 32x32 PNG |

> Drop your files directly into this `assets/` folder. The README files in the root and in `profile/` are pre-configured to link with these paths.
