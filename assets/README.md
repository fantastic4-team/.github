# Fantastic 4 Assets

This directory stores all visual assets for the Fantastic 4 GitHub Organization profile.

### Asset Manifest
| File Name | Purpose | Dimensions / Format |
|---|---|---|
| `banner.png` | Hero header banner | Full width PNG |
| `square.png` | Flanking cards for social handles grid | 1254x1254 Square PNG |
| `saturn.png` | Engineering architecture track illustration | 1264x1244 Square PNG |
| `footer.png` | Bottom profile footer banner | Full width PNG |
| `Tech Stack banner.png` | Technology stack section banner | 2159x164 Banner PNG |
| `fantastic4-emblem.svg` | Team emblem | Vector SVG |
| `icon-1.svg` to `icon-4.svg` | Double-line numbered track icons | Vector SVG |
| `icon-share.svg` | Clean share / external link icon | Vector SVG |

> Drop your files directly into this `assets/` folder. The README files in the root and in `profile/` are pre-configured to link with these paths.
